配置文件不包含在安装包中。

## 安装

将包内 `cep` 文件夹放到用户 CEP 扩展目录：
`~/Library/Application Support/Adobe/CEP/extensions/`。
重启 Photoshop 后打开“窗口 > 扩展（旧版）> AI 换鞋 Demo（PS2024）”。
不要与同一扩展 ID 的旧版同时安装。保留旧版备份在 extensions 目录之外。
未签名开发扩展需要本机已有 CEP 开发加载设置。

## 操作

1. 打开 PSB，点击“扫描标记”，可导出每层标签、ID、边界、继承角色、跳过原因与错误。
2. 导入真实 Excel，创建工作副本。原文档不被写入。
3. 输入离线目录或 Eagle library 路径并读取素材库。
4. 每个任务确认 Excel 款色；没有唯一货号匹配时由设计师选择，不能交给 AI 猜。
5. 素材没有登记时，可展开“登记离线素材对应关系”，选择 Excel 款色、透明鞋 PNG 和多角度参考图，写入当前目录的 `shoe-materials.json`。
6. 点击“定位图层”，在 Photoshop 用选区工具明确选出允许修改的鞋位及必要融合区域，再点击“按选区置入素材”。
7. 调整真实鞋素材位置、比例、旋转及遮挡。组蒙版限制其影响范围。不要删除或修改 `AI-Shoe-mask-*` 通道。
8. 点击“确认合成并生成”。请求包含已合成局部画面和该任务唯一素材组，使用 Excel 的真实货号色号。
9. 返回图必须可解码、尺寸一致；程序保留区域外像素，并通过保存的选区蒙版再次限制回写。失败不回写 AI 结果，保留可编辑素材合成。
10. 逐个验收 Logo、结构、纹理、配色、遮挡和光影，另存新的 PSB 文件。禁止覆盖现有文件。

颜色标签只确定候选图片，不能确定每只鞋的轮廓。这版需要人工选区和合成确认，
不是自动识别全部鞋位的一键无人值守版本。两个鞋位的边界矩形重叠时暂时阻止处理，
避免交叉覆盖；复杂遮挡应由设计师拆分确认。
当前严格支持 RGB 8 位文档，避免隐式色彩与位深转换。
任务文件和报告保存在 `~/Pictures/AI-Shoe-Tasks/`；API 原始输出在 `~/Pictures/AI-Shoe-Results/`。
重载面板会丢失当前宿主会话，必须重新建立任务；保留的工作副本和任务报告可供人工恢复。

## 素材索引

离线目录与 Eagle 库根目录均可使用 `shoe-materials.json`：

```json
{
  "materials": [
    {
      "id": "unique-set-id",
      "sku": "GW2000",
      "color": "藕粉",
      "cutout": "GW2000-cutout.png",
      "references": ["GW2000-side.png", "GW2000-logo.png"]
    }
  ]
}
```

路径相对索引文件或为绝对路径。抠图必须透明且非空，普通白底商品图不能直接合成。
同一款色多个素材组或无素材组都阻止生成；同一组多个角度不是歧义。
不修改 Eagle 内部数据。若无根目录索引，可只读 Eagle `images/*.info/metadata.json`：
每张鞋素材需要唯一 `sku:货号`、`color:色号`、`shoe-set:素材组ID`、
`role:cutout` 或 `role:reference` 标签。每组须有唯一抠图和至少一张参考图。
未有这些明确对应关系时不会根据文件夹排列、相似名称或图片内容猜款色。
