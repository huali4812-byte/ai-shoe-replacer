# AI 换鞋 Demo 0.2.0

此版本用于在 Photoshop 验证 Excel 解析、图层标色读取、款色确认和独立图层组创建。
尚未接入 Nano Banana 2、素材库、鞋位图像识别或自动成图导出。测试图层是透明空白层，画面不会变鞋。

## 加载到 Photoshop 2026

1. 在 Creative Cloud 桌面应用中安装 Adobe UXP Developer Tool。
2. 在 Photoshop 设置 > 增效工具（Plugins）中启用开发人员模式，按提示重启 Photoshop。
3. 打开 Adobe UXP Developer Tool，点击 Add Plugin，选择本目录的 manifest.json。
4. Photoshop 保持打开，点击该插件的 Load。通过 Photoshop 的增效工具菜单打开 AI 换鞋 Demo 面板。
5. 修改代码后，在 UXP Developer Tool 中 Reload。开发插件不能通过拖入 PS 或放进传统 Plug-ins 文件夹安装。

## 本次测试

1. 打开用户提供的新版平销款模版.psb。
2. 在面板中导入基诺浦26冬款.xlsx。
3. 点击扫描当前文档。
4. 对没有明确货号的图层选择目标款色并确认。红色建议主推，绿色建议次推。紫色生成两个位置，分别确认目标款色。
5. 点击创建测试图层。遇到未确认任务会暂停，确认后再次点击继续。已完成任务不会在本次扫描中重复创建。
6. 在图层面板查看以 [换鞋测试] 开头的独立组，每组包含一个透明占位层。
7. 可以导出 JSON 任务报告。需要保存测试文档时使用 Photoshop 的另存为，保存到新路径，避免覆盖原始 PSB。

原图层不会被修改。再次扫描或重新加载插件会重置本次任务状态，重新执行会创建新的测试组。
扫描可见的红、绿、紫标色像素层和智能对象，支持父组标色继承。文字、调整图层、隐藏图层和测试组会被跳过。
一个标色图层表示候选图片，尚不代表已识别该图片内的每一只鞋。

## 当前 Excel 规则

- 订单明细使用 E 列货号、F 列色号，支持合并单元格货号与字体/富文本颜色。
- 红字为主推、绿字为次推；无法确认时保留为空，不按排列顺序猜测。
- Sheet2 只有货号，不能用于款色匹配。
- 不依据 Excel 的超大空白区域遍历百万行，仅检查实际单元格。
- GW/Y1972 等复合货号保持原样，未猜测 Eagle 中的别名。
