# Photoshop AI 智能换鞋插件

面向电商商品图批量换款的 Photoshop CEP 工具，将人工整理素材、指定款色、换鞋、结果复核等步骤整合为可操作的 AI 工作流。

## 项目与个人贡献

- **业务场景**：设计组需要处理大量图层复杂、包含多个换款任务的 PSB 商品模板。
- **负责范围**：独立对接设计师需求，完成产品方案设计、插件开发、调试和持续迭代。
- **提效反馈**：单份复杂 PSB 的常规处理流程从人工约 **4–5 小时**缩短至 AI 流程约 **30 分钟**；支持批量任务和夜间自动处理的工作方式。这里的时间单位是**每份复杂 PSB 文件**，并非每张普通图片；实际处理时间受素材、任务数量、重试次数和人工验收影响。

## 核心能力

1. 读取 Photoshop 智能对象和设计师事先设置的图层标色，判定任务场景。
2. 从 Excel 获取目标货号与主推/次推款色，按 SKU 关联商品素材。
3. 结合视觉检测、多模态图像生成和图像合成，生成候选换鞋效果。
4. 在独立工作副本中处理与写回 PSB，避免直接覆盖原始文件。
5. 提供结果复核、候选重做、任务诊断和批量处理支持。

## 技术栈

Adobe Photoshop CEP / ExtendScript (JSX)、JavaScript、Node.js、Python、视觉检测、多模态图像生成 API。

## 本地运行要求

此仓库不包含真实商品素材、内部素材库、授权 API 凭证或本机视觉运行环境。

- 适配目标为 Photoshop 2024 的 CEP 扩展；本地部署需要相应 Photoshop、Node.js 和 Python 环境。
- API 凭证须存放在本机私有配置中，不可提交到 Git。
- 本地视觉解释器可以通过环境变量 `AI_SHOE_PYTHON` / `AI_SHOE_ARCH` 配置，或者在安装目录放置**不参与版本控制**的 `cep/vision-runtime.json` 文件，例如：

```json
{"python":"/path/to/local/venv/bin/python","architecture":"arm64"}
```

## 验证说明

仓库中的代码实现、离线测试、模型生成、Photoshop 实机写回和设计师最终视觉验收是不同层级。实际业务应用仍需人工审核款色、鞋型、Logo、透视和背景一致性，不能把自动生成直接视为全部通过验收。
